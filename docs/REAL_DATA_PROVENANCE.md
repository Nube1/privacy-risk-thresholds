# Public data: which run each figure comes from

Two census runs exist in this repository. They use the same public file but differ in
the protection grid and the attack draws, so their frontiers differ. Quote the current
run in manuscripts; quote the archived run only as archived evidence.

## Current manuscript run (`artifacts-paper/results.json`, section `real.census`)

This is the run the long form (`paper/bis_ifc_full.tex`, Section "Real data") and the
book report. It is regenerated by `scripts/rebuild_evidence.py`.

Census frontier upper-risk range (eight of 25 settings, simultaneous bounds): 0.276 to 0.942.

## Archived exploratory run (`artifacts-real/`)

These figures are retained from earlier exploratory runs and were not rerun by later
expansions. Values belong to their original attack laws and public samples; they do not
measure confidentiality of a hidden population, and the current journal article does
not claim a neural audit improvement from them.

Archived Census frontier upper-risk range: 0.276 to 0.547.

Archived exploratory sensitivity rates: 0.371, 0.271, 0.186, 0.179, 0.137, 0.093.

manuscript, and the archived values against this report only.
