# Governing Disclosure Risk (book draft)

Working draft of a book that expands the privacy risk papers in this repository. Private until
publication.

Build with `latexmk -pdf main.tex` from this folder. Figures are read from `../paper/diagrams` and
`../paper/figures`, so build inside the repository. The compiled draft is
`Mahomane_Governing_Disclosure_Risk_draft.pdf`.

First full draft: preface, eighteen chapters with proofs and an appendix mapping the software. Each
chapter follows the structure in `STYLE.md`: it states a common belief, breaks it with evidence from
this repository, asks one question, and answers it while alternating between a human thread and the
technical argument. Every number carries a `% source:` comment naming the file it came from.
`REVIEW.md` records the review of the arguments and code, and discrepancies found while writing.
