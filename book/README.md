# Governing Disclosure Risk (book draft)

Working draft of a book that expands the privacy risk papers in this repository. Private until
publication.

Build with `latexmk -pdf main.tex` from this folder. Figures are read from `../paper/diagrams` and
`../paper/figures`, so build inside the repository. The compiled draft is
`Mahomane_Governing_Disclosure_Risk_draft.pdf`.

Drafted so far: preface, Chapter 1 (a risk figure is not a decision), Chapter 2 (risk as the outcome
of a declared attack) and Chapter 9 (several releases to the same user). The other chapters are
planned and appear in the PDF as short plans. `REVIEW.md` records the review of the arguments and
code that the book starts from.
